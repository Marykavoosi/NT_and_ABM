## Lab exercise

For one real spatial cell network:

1. Compute the degree distribution.
2. Compute clustering.
3. Compute the mean shortest-path length.
4. Generate Erdős–Rényi graphs with matching network size and mean degree.
5. Compare the real and random networks.
6. Compare the giant-component size with the Newman N11 theoretical prediction.
