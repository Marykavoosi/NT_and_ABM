# Data

## Primary dataset

NCBI GEO accession:

**GSE309522**

The dataset contains Xenium spatial transcriptomics samples from mouse mesenteric lymph nodes in the context of persistent Salmonella infection.

For the network analysis, individual cells will be represented as nodes and spatial neighbourhood relationships will define edges.

## Directory structure

- `raw/` — original downloaded files; not tracked by Git
- `processed/` — derived datasets that are small enough to reproduce the analyses

## Reproducibility

Raw files should be downloaded directly from GEO.

The exact sample selected for the course analyses will be documented here once the WT samples have been compared.

Access:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE309522
